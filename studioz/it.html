4) تطبيق Microsoft 365 لقراءة البريد من جوه السيستم

Entra admin center ← App registrations ← New registration: الاسم Ninety System Mail، Single tenant، بدون Redirect URI. ثم API permissions ← Microsoft Graph ← Application permissions: Mail.Read + Mail.Send + User.Read.All ← Grant admin consent. ثم Certificates & secrets ← New client secret (24 شهر) — انسخ Value مش Secret ID.

قصر الصلاحية على الصناديق الأربعة (Exchange Online PowerShell): restrict the app to the four mailboxes:

New-DistributionGroup -Name "NinetySystemMail" -Type Security -Members info@ninetystudioz.com,hello@ninetystudioz.com,accounts@ninetystudioz.com,mahmoud.fawzy@ninetystudioz.com
New-ApplicationAccessPolicy -AppId <Application ID> -PolicyScopeGroupId NinetySystemMail@ninetystudioz.com -AccessRight RestrictAccess -Description "Ninety system mail"

لو مش Microsoft 365 سيب الخانات دي فاضية واكتب في الملاحظات. Not on Microsoft 365? Leave these empty and tell us in the notes.
