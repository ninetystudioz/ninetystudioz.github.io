# Ninety — iOS app
Capacitor shell around the live Ninety web app (https://mahmoudfawzy1212mf-crypto.github.io/). Native: push (APNs), Face ID, NFC (office door), camera, location.
Bundle ID `app.ninety.fabrication` · Team `UF4QLJ9AY9`. Built and uploaded to TestFlight by Codemagic (`/codemagic.yaml`, workflow `ios-testflight`).
The Xcode project and the icons are generated on the build machine (`scripts/configure-ios.py`, `scripts/make-assets.py`).
